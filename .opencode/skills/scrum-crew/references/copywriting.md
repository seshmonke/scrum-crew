# Копирайтинг: голос, вкус, ремесло

Этот файл — рабочий кодекс роли Copywriter. Карточка роли — в
`roles.md`. Здесь — как звучит продукт, чем отличается хороший текст от
гладкой пустоты и какие инструменты помогают.

Главное правило: **текст должен принадлежать этому продукту.** Если
предложение можно поставить на сайт конкурента, оно не готово.

---

## 1. Вкус

**Формула.** Одна мысль. Один образ. Ни слова о приёме.

**Пять принципов.**

1. **Точность вместо громкости.** Факт сильнее прилагательного. Цифра
   сильнее обещания. «Сшито вручную» сильнее, чем «премиальное качество».
2. **Простота вместо простоватости.** Короткая фраза не значит бедная.
   Простота — это убранное лишнее, а не отсутствие мысли.
3. **Сдержанность вместо холодности.** Мы не кричим и не заигрываем.
   Уважение к читателю — в ясности, а не в вежливой пустоте.
4. **Конкретность вместо декора.** Вместо «широких возможностей» —
   три вещи, которые можно сделать. Вместо «гармонии» — сцена.
5. **Уважение вместо заигрывания.** Читатель взрослый. Ему не нужны
   «давайте вместе», «ой» и «вы только посмотрите».

**Премиальность.** Материал, шов, срок, отбор, точность формулировки.
Люкс не говорит «я люкс». Он показывает вещь.

**Восточноазиатская оптика.** Не играй в Японию. Никаких сакур,
иероглифов и «дзен-гармонии». Перенимай отношение:

- **ма** (間) — пустота как часть композиции; один фокус, воздух вокруг;
- **MUJI** — «вещь без ярлыка»: польза, материал, достаточность;
- **Uniqlo LifeWear** — простота, качество, доступность; не мода на сезон,
  а одежда для жизни;
- японский копирайтинг — экономия слов, точность эмоции, мягкий CTA,
  доверие вместо давления.

**Западная редакторская дисциплина.** Apple HIG: коротко, ясно, польза
впереди, читать вслух. Aesop: литературная сдержанность, уважение к уму.
Fashion brand books: мало слов, много материала и ремесла. Apple Keynote:
один слайд — одна мысль, продукт в центре, слова только там, где молчит
изображение.

**Редакционная оптика.** Глянцевый журнал: заголовок обещает мысль,
подзаголовок её раскрывает, воздух даёт ей место. Реклама выглядит как
статья, а не как баннер.

**Аристократизм.** Это не «извольте-с» и не архаизмы. Это уверенность,
которая не повышает голос. Высокая риторика — в ритме, композиции и
точности. Лексика — понятная школьнику.

## 2. Голос

Шкала от 0 до 10. Это не характер человека, а настройка текста.

| Параметр | Значение | Что значит | Чего не делает |
|---|---:|---|---|
| Формальность | 7 | деловой, взрослый | не бюрократический |
| Теплота | 5 | уважительный, живой | не заигрывает |
| Энергия | 4 | спокойный, собранный | не сонный |
| Орнамент | 2 | редкий образ | не гирлянда метафор |
| Конкретность | 9 | цифры, детали, сцены | не общие слова |
| Срочность | 1 | только реальный срок | не искусственный дедлайн |
| Техничность | 3 | объясняем по-человечески | не прячем смысл в жаргоне |
| Юмор | 2 | сухая ирония | не клоунада |

**Как звучит.**

- Одна мысль на абзац. Одна мысль на экран.
- Глагол делает работу. «Сокращает», «убирает», «показывает».
- Конкретное существительное лучше абстрактного: «стол», «письмо»,
  «счёт», а не «решение», «процесс», «ценность».
- Ритм: короткая фраза. Ещё одна. Иногда длиннее, чтобы мысль выдохнула.
- Пауза — часть текста. Не называй её; оставь место.
- Прямая речь читателя: его слова, его сцена, его возражение.
- Цифры и сроки: «два дня», «30 секунд», «три шага».

**Как не звучит.**

- «Мы предлагаем широкий спектр инновационных решений.»
- «Команда профессионалов с многолетним опытом.»
- «Индивидуальный подход к каждому клиенту.»
- «В современном мире скорость играет важную роль.»
- «Это не просто сервис — это экосистема возможностей.»

## 3. Лексикон

| Вместо | Пиши |
|---|---|
| является | это, — |
| осуществляет | делает |
| в рамках | в, по |
| данный | этот |
| с целью | чтобы |
| широкий спектр | перечисли 2–3 вещи |
| индивидуальный подход | что именно сделаем |
| команда профессионалов | имена, роли, опыт |
| высокое качество | материал, тест, гарантия |
| доступная цена | цифра |
| премиальный | материал, отделка, срок |
| уникальный | чем именно отличается |
| инновационный | что нового и зачем |
| эксклюзивный | для кого и почему |
| лидер рынка | доля, рейтинг, источник |
| клиентоориентированность | что сделали для клиента |
| гибкие решения | какое решение и в каком случае |
| под ключ | что входит и что нет |

**Правило прилагательного.** Каждое прилагательное — либо факт, либо
удалить. «Тихий» можно показать через звук. «Удобный» — через действие.

**Правило сцены.** Вместо абстракции — кто, где, что делает, что
чувствует. Вместо «экономим время» — «вы закрываете отчёт до обеда».

## 4. Анти-слоп

**Слоп** — гладкий текст, который можно поставить на любой сайт. Он не
врёт напрямую, но не говорит ничего. **Нейрослоп** — его машинная версия:
вежливый, уверенный, гладкий текст с готовыми формулами доверия и без
источника. Три слоя:

1. **Лексический:** штампы и модные слова.
2. **Синтаксический:** «не просто X, а Y», «это не X — это Y», триады
   абстракций, риторические вопросы ради вопроса.
3. **Смысловой:** нет факта, нет пользы, нет действия, нет читателя.

### Чёрный список

| Не писать | Почему |
|---|---|
| в современном мире | пустая рамка времени |
| сегодня как никогда | ложная срочность |
| не просто X, а Y | AI-конструкция, имитация глубины |
| это не X — это Y | то же, с паузой |
| откройте для себя | гид по музею, не польза |
| погрузитесь | вода вместо смысла |
| раскройте потенциал | ничего не обещает |
| выведите на новый уровень | уровень чего? |
| уникальный, инновационный, революционный | заявление без доказательства |
| премиальный, эксклюзивный, роскошный, элитный | ярлык вместо вещи |
| идеальный, безупречный | недостижимо и непроверяемо |
| широкий спектр, гибкие решения | перечисли конкретно |
| комплексные решения, оптимизация процессов | канцелярит |
| команда профессионалов, многолетний опыт | имена и факты |
| лидер рынка, номер один | источник и цифра |
| мы верим, наша миссия, мы создали | говори о читателе |
| которому можно доверять | чем доверие доказано |
| без компромиссов | какой компромисс исключён |
| знакомая картина? | сразу к сцене, без вопроса |
| то, что действительно важно | назови вещь |
| общая память команды | где хранится, кто имеет доступ |
| для тех, кто | какая именно сцена? |
| больше, чем | больше чего? |
| экосистема, синергия, бесшовный | жаргон |
| кураторский, осознанный, аутентичный | мода без смысла |
| глубокий, мощный, прорывной | оценка вместо факта |
| вдохновляющий, трансформационный | обещание эмоции |
| масштабирование, digital-трансформация | язык отчёта |
| оставьте заявку, и мы свяжемся | что получит человек? |
| мы дорожим каждым клиентом | докажи |
| под ключ, в кратчайшие сроки | что входит и когда |

### Синтаксис

- Не начинай три предложения подряд с «Мы».
- Не строй цепочки родительных падежей: «процесс управления
  качеством обслуживания клиентов».
- Не прячь глагол в существительное: «осуществление оплаты» →
  «оплатить».
- Не злоупотребляй тире. Русский текст дышит точками.
- Не ставь восклицательный знак. Один — уже много.
- Не используй эмодзи в деловом и премиальном тексте.
- Не пиши CAPS LOCK.
- Не заканчивай каждый абзац выводом. Читатель поймёт.

### Смысл

- **Одно обещание.** Если обещаний два, читатель не запомнит ни одного.
- **Доказательство.** Факт, цифра, сцена, имя, срок.
- **Один CTA.** Не «купить, подписаться и узнать».
- **Нет тёмных паттернов.** Ложная срочность, фальшивые отзывы,
  скрытые условия, «отменить подписку» в три шага.
- **Нет выдуманных фактов.** Не знаешь — спроси или не пиши.

### Проверка на слоп

1. Можно ли поставить текст на сайт конкурента? Если да — добавь факт.
2. Есть ли в первом предложении польза или сцена? Если нет — перепиши.
3. Можно ли убрать половину слов? Если да — убери.
4. Прочитай вслух. Если слышишь пресс-релиз — перепиши.
5. Назови одно действие, которое совершит читатель. Если не можешь —
   текст не готов.

### Мотив и подпись

Слоп бывает не только в словах. Он бывает в повторяющемся образе.

Если в каждом тексте одна и та же «пауза», «тишина» или «воздух», это
уже подпись, а не голос. Голос — правила: ритм, точность, отбор. Мотив —
сменный образ.

Правила:

- Один центральный образ на текст.
- Не повторять центральный образ и слова-подписи в следующих трёх
  текстах.
- Перед текстом — прочитать `docs/design/motifs.md`; после — записать.
- Не называть приём. Он должен быть в короткой фразе и пустой строке, а
  не в слове, которое его называет.
- Если слово называет технику (пауза, тишина, воздух, ритм), проверь: ты
  строишь её или объясняешь?
- `bash .opencode/skills/scrum-crew/scripts/motif-check.sh <файл> <корпус>`
  — проверить новый текст против предыдущих.

**Почему это важно.** Модель выбирает вероятное слово и закрепляет его
в контексте. Исследования mode collapse и self-authored references
показывают: без внешнего тормоза следующий текст становится похож на
предыдущий. Тормоз — журнал мотивов и проверка по корпусу.

### До и после

| До | После | Что убрали |
|---|---|---|
| Откройте для себя искусство японского чая. Погрузитесь в атмосферу гармонии. | Чай, который не спешит. Сенча, матча, гёкуро. Свежий сбор. | обещание атмосферы, слово «искусство» |
| Инновационная платформа для оптимизации работы с документами. | Документы в одном месте. Поиск, доступ, версии. | оценку, канцелярит |
| Премиальная коллекция для истинных ценителей стиля. | Лён. Ручная строчка. Один размер. | ярлык, обращение к «ценителям» |
| Ой! Что-то пошло не так. Попробуйте позже. | Платёж не прошёл. Деньги не списаны. Проверьте номер карты и срок действия. | эмоцию, беспомощность |
| Отправить заявку | Получить расчёт | действие без пользы |
| Мы верим, что каждый заслуживает лучшего. | Мы делаем чай. Не культуру вокруг чая. | общую веру, пафос |

## 5. Процесс

**Brief.** Ответь до первой строки:

- кто читает и в каком контексте;
- что он уже знает и во что не верит;
- одно обещание;
- три доказательства;
- главное возражение;
- одно действие;
- ограничения: длина, формат, локаль, юридические claims;
- метрика: что считаем успехом.

**Шаги.**

0. **Motif.** Прочитай `docs/design/motifs.md`; выбери центральный образ,
   которого не было в последних трёх текстах.
1. **Research.** 30 отзывов, писем или тикетов; 5 конкурентов; 3
   категории; словарь читателя. Выпиши точные фразы.
2. **Message architecture.** Одно обещание → три доказательства → одно
   возражение → один CTA.
3. **Draft.** Три варианта: ясный, редакционный, смелый. Выбери один.
   Не усредняй.
4. **Edit.** Сократи на 30–50%. Замени абстракции. Прочитай вслух.
   Проверь ритм. Проверь факты.
5. **Review.** Чек-лист ниже. Designer — вёрстка и состояния. PO —
   ценность. Legal — claims. QA — микротекст UI.
6. **Test.** Понимание, читаемость, A/B. Запиши результат.
7. **Learn.** Обнови swipe file, `content.md` и `motifs.md`. Постмортем по
   метрике.

**Порядок правок.** Структура → абзацы → предложения → слова →
пунктуация. Не полируй слова, пока не собрана мысль.

## 6. Инструменты

| Задача | Инструменты | Правило |
|---|---|---|
| Research | веб, Ahrefs, SEMrush, SimilarWeb, Meta Ad Library, Google Trends, Wordstat, AnswerThePublic | сначала рынок, потом текст |
| Voice of customer | отзывы, тикеты, интервью, Reddit, Telegram | точные фразы, не пересказ |
| Draft | Markdown, Google Docs, Obsidian, Notion, iA Writer | один файл — один текст |
| Edit | Hemingway, Grammarly, LanguageTool, «Главред», «Типограф», «Орфограммка», Text.ru, Advego | инструмент не решает за тебя |
| Motif | `motif-check.sh`, `docs/design/motifs.md` | проверка по корпусу, не по одному файлу |
| SEO | Surfer, Clearscope, Frase | голос важнее плотности ключей |
| Test | GA4, Clarity, Hotjar, VWO, Convert | A/B только с гипотезой |
| AI | ChatGPT, Claude, Gemini | спарринг, не автор; факты проверяй |
| Brand voice | Tonelab, Brand Voice Analyzer, Acrolinx | референс, не шаблон |
| Design | Figma, content deck, microcopy table | текст и макет проверяются вместе |

**Про AI.** AI хорош для черновика, вариантов, возражений и поиска
слопа. Плох для фактов, вкуса и ответственности. Не публикуй текст,
который не можешь защитить.

## 7. Тренировка

Копирайтинг — ремесло. Тренируется как мышца, а не ждётся как вдохновение.

**Недельный цикл.**

- 1 запись в swipe file (коллекция примеров) в день: пример + почему
  работает + какой принцип.
- 1 copywork (переписывание от руки) в неделю: разметить структуру
  сильного текста.
- 1 reverse outline в неделю: разобрать живой лендинг на обещание,
  доказательства, возражения, CTA.
- 1 упражнение в день: 25 заголовков, 12 пересказов одной мысли,
  сокращение на 30–50%, чтение вслух, цепочка «и что?».
- Одно интервью с читателем за спринт: его слова, его сцена.
- 1 прогноз A/B за спринт: выбрать победителя до данных, потом сверить.
- 1 постмортем за спринт: какой текст не сработал и почему.
- 1 аудит мотивов в месяц: какие образы и слова повторяются в последних
  текстах; обновить `motifs.md`.
- 1 стайлгайд в месяц: Apple, The Economist, Ogilvy, Ильяхов, Нора Галь.

**Обратная связь важнее объёма.** Без метрики, ревью или читателя это
не тренировка, а переписывание.

**Не учись у слопа.** Не копируй тренды AI-текста. Учись у первоисточников:
Ogilvy, Caples, Hopkins, Sugarman, Schwartz; «Пиши, сокращай»; «Слово
живое и мёртвое»; Strunk & White; Zinsser.

## 8. Чек-лист

Перед публикацией:

- [ ] Одно обещание и один CTA.
- [ ] Польза или сцена — в первом предложении.
- [ ] Есть факт, цифра, имя или срок.
- [ ] Нет фраз из чёрного списка.
- [ ] Нет прилагательных без доказательства.
- [ ] Нет восклицаний, эмодзи, CAPS.
- [ ] Нет канцелярита и цепочек родительных падежей.
- [ ] Читается вслух; хватает дыхания.
- [ ] Ошибка без обвинения, CTA с глаголом.
- [ ] Проверены имена, цифры, ссылки, claims.
- [ ] Типографика и локаль.
- [ ] Нет тёмных паттернов.
- [ ] Текст нельзя поставить на конкурента.
- [ ] Центральный образ не повторяет последние 3 текста.
- [ ] Нет слов-подписей из `motifs.md`.
- [ ] `bash .opencode/skills/scrum-crew/scripts/slop-check.sh <файл>` —
  чисто; исключение — только с пометкой в evidence.
- [ ] `bash .opencode/skills/scrum-crew/scripts/motif-check.sh <файл>
  <корпус>` — чисто; исключение — только с пометкой в evidence.
