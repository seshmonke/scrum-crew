# Аудит методологии

Отчёты мета-роли **Methodology Auditor**. Смотрит не на продукт, а на то,
как работает система агентов.

## Когда появляется отчёт

- После 3-го закрытого спринта — автоматически, если есть материалы.
- По команде «аудит методологии».
- Вне графика: 3 мимо Goal, rework > 30%, конфликты > 15%, cost/task +30%,
  два инцидента, нарушения границ ролей.

## Готовность

- **pilot:** ≥ 1 закрытый спринт, ≥ 5 merged задач, есть `retro.md` и
  метрики.
- **full:** ≥ 3 спринта, ≥ 20 merged, ≥ 20 событий, 2+ ретро.

Нет условий — `No audit: insufficient material`, отчёт не создаётся.

## Формат

`NN-YYYY-MM-DD.md` по шаблону
`.opencode/skills/scrum-crew/assets/audit.md`.

- максимум 3 находки;
- каждая с доказательством, root cause, proposal, owner, метрикой;
- изменения — через ADR/PR, не в спринте;
- в следующем аудите — проверка эффекта;
- нет эффекта два аудита — роль удаляется.
