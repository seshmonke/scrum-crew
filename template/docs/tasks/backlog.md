# Бэклог

> **Context:** `status: active` · `updated: YYYY-MM-DD` · `owner: PO` ·
> `sprint: —` · `task: —` · `change: —` ·
> links: [.scrum/README.md](../../.scrum/README.md) · [INDEX](INDEX.md)

Весь пул задач без привязки ко времени. Порядок — приоритет.

Формат строки:

```
- [ ] P1. Короткий глагол: что сделать. Критерий: как проверить.
      Источник: откуда взялось. Спринт: —.
```

Метки:
- **P0** — блокирует главный сценарий, угрожает данным или безопасности.
- **P1** — частый сценарий или заметная масса без пользы.
- **P2** — остальное.
