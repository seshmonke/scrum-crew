# Milestones

Концептуальные решения и отмены. Формат строки:

```
- ДД.ММ.ГГГГ. Что решили. Чем заменили (если отмена). Спринт N.
```

Сюда попадает:
- выбор продукта, стека, провайдера, модели монетизации;
- изменение публичного контракта;
- отменённое решение по правилу сжатия;
- всё, что меняет направление проекта.
