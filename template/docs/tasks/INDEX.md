## Правила

- Вход для агента — [`.scrum/README.md`](../../.scrum/README.md), а не этот
  файл.
- Состав спринта не придумывать: сначала согласовать с владельцем, потом
  зафиксировать файлом.
- Один спринт — один файл `.scrum/sprints/NN/sprint.md` с trace-таблицей;
  старые `docs/tasks/NN-*.md` остаются историей.
- В работе — 1–2 задачи; WIP 6 — потолок. Общие файлы/контракты —
  последовательно.
- Всё, что всплыло, сразу задачей в бэклог с глаголом и приоритетом.
- После закрытия файл спринта остаётся историей: не удаляется.
- Brief/report/handoff/evidence — в `.scrum/sprints/NN/tasks/<id>/`.
- Доска — про статус; содержание решений — в чистовике и OpenSpec.
